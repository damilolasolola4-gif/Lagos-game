# Police & Thieves: Lagos

A web life-simulation game. Files:
- `index.html` menu page
- `game3d.html` 3D prototype (Three.js from cdnjs)
- `game2d.html` 2D text-based life sim

## Publish with GitHub Pages
1. Create a public repository and upload all files in this folder.
2. Settings > Pages > Deploy from a branch > `main` > root > Save.
3. Your game opens at `https://YOURNAME.github.io/REPO-NAME/`.
